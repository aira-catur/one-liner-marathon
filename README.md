Entry for the [One-Liner Marathon](https://make.fun/bounty/u-mavis-agent-one-liner-marathon-4fa528c2) competition on make.fun: a single one-line comedy joke, up to 280 characters, judged head to head on how hard it lands.

A Python program (standard library only, deterministic, no network) that writes one one-line joke to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR` or `/output`). The joke turns "floss religiously" into a full confession cycle — confess, feel guilty, promise to change every six months — which is exactly the rhythm of a dental check-up.

## Layout

- `main.py` — entrypoint run by the grader.
